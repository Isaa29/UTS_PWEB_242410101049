Aplikasi ini merupakan website sederhana yang dibuat menggunakan Laravel dengan konsep MVC untuk memenuhi tugas UTS Pemrograman Web. Website ini mengambil tema pengelolaan rental motor dengan nama “Rental Motor Jaya”. Di dalamnya terdapat beberapa halaman utama seperti login, dashboard, profil, dan pengelolaan data. Pengguna dapat memasukkan username pada halaman login, kemudian data tersebut akan diteruskan ke halaman dashboard dan profil untuk ditampilkan. Selain itu, terdapat halaman pengelolaan yang menampilkan data motor, customer, dan transaksi dalam bentuk array yang diolah dari controller dan ditampilkan secara dinamis menggunakan Blade. Website ini dibuat tanpa menggunakan database, sehingga seluruh data masih bersifat statis
